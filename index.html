K-Means clustering with Python — Civil Registration Office of Bogor City

K-Means Algorithm
Python Language

Project Overview

This project applies unsupervised machine learning using the K-Means clustering algorithm to group sub-districts in Bogor City based on population characteristics. The primary goal is to assist Disdukcapil Kota Bogor in identifying priority regions for birth certificate issuance programs (penerbitan akta kelahiran) and optimizing administrative field operations.

Key Features

  • K-Means clustering to categorize sub-districts by population density & demographic indicators
  • Elbow method analysis for optimal cluster number determination
  • Visualization of cluster centroids and spatial distribution for policy interpretation

Classification · Healthcare AI

Early Detection of Preeclampsia

KNN Machine Learning Model & Web Application — Skripsi (SIDINI)

KNN Algorithm
Python Language
GitHub Repository

Project Overview

Building a machine learning classification model using the K-Nearest Neighbor (KNN) algorithm to detect early risk of preeclampsia in pregnant women based on health center (Puskesmas) examination data. The model evaluates clinical variables such as blood pressure, urine protein, and medical history to detect risk accurately and support preventive medical intervention. Integrated with the SIDINI web application for real-time screening.

Key Features

  • KNN classification model for preeclampsia risk prediction in pregnant women
  • Data preprocessing, normalization, and feature selection from Puskesmas clinical records
  • Model performance evaluation using accuracy, precision, F1-Score, and recall metrics
  • Integrated SIDINI web application for real-time screening input and decision support
