Project Overview

This project applies unsupervised machine learning using the K-Means clustering algorithm to group sub-districts in Bogor City based on population characteristics. The analysis helps identify which areas should be prioritized for birth certificate issuance programs.

By categorizing regions into distinct clusters based on factors such as population size and demographic features, the model provides actionable insights for government resource planning and service distribution.

Key Features

  • K-Means clustering to group sub-districts by population characteristics
  • Elbow method for optimal cluster number determination
  • Visualization of cluster results for interpretability
