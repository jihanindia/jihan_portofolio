Project Overview

This project was developed during the internship at Dinas Kependudukan dan Pencatatan Sipil Kota Bogor. The goal was to create an interactive dashboard in Tableau that visualizes population distribution data across different sub-districts in Bogor City.

The visualization helps the civil registration office efficiently monitor population counts by area, enabling data-driven decisions for resource allocation and public services.

Key Features

  • Interactive regional breakdown of population data by sub-district
  • Visual comparison charts for easy monitoring and reporting
  • Filter and drill-down capabilities for deeper analysis
